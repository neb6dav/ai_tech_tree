Research questions and open direction

Questions

  • Can enforceable least-privilege and containment policies for adaptive tool-using agents survive realistic prompt injection, delegation, persistence, privilege escalation, and sandbox-escape attacks?

Open direction

Can enforceable least-privilege and containment policies for adaptive tool-using agents survive realistic prompt injection, delegation, persistence, privilege escalation, and sandbox-escape attacks?

Closure criteria

Specify the policy and threat model formally; enforce it below the model layer; test benign utility and adaptive attacks across real tool classes, delegation, memory, restart, identity, network, and code execution; show bounded failure probability under repeated trials; and obtain an independent penetration test.

Claim state: Editorial hypothesis · High confidence

Partial results

  • AI Control shows that monitoring and protocol design can improve safety even when an untrusted model intentionally subverts a coding task. AgentDojo and Agent Security Bench provide realistic tool-agent prompt-injection and security suites, while SandboxEscapeBench tests container-escape capability. These are substantial defenses and measurements, but none establishes general containment under an adaptive real-tool threat model.

Counterexamples and limits

  • AI Control demonstrates that trusted monitoring, auditing, and protocol design improve outcomes against an intentionally subversive untrusted coding model, within a bounded backdoor-insertion setting.
  • AgentDojo contains 97 benign tasks and 629 security test cases across four tool domains; tested agents and defenses still trade off utility and security.
  • Agent Security Bench spans ten scenarios, more than 400 tools, and roughly 90,000 tests, while SandboxEscapeBench adds realistic container-escape tasks; neither alone proves containment.

Novelty review

Status: Targeted search. Checked: 2026-08-04. Targeted arXiv searches for AI control, agent containment, agent security benchmarks, prompt injection, capability control, least privilege, tool authorization, container escape, adaptive red teaming, and 2024-2026 follow-on work; reference chaining from AI Control, AgentDojo, ASB, and SandboxEscapeBench. High confidence that enforceable containment surviving adaptive attacks in realistic tool environments remains open. Empirical defenses and control protocols are active and valuable, so the claim is not that no defenses exist. No universal impossibility or priority claim is made.

Estimated effort: Individual: One workstation, containerized tools, and one or two local or API models; no live secrets or production accounts. · SmallLab: Four to eight model families, hardened microVM infrastructure, security engineering, and an adaptive red team. · WellFundedLab: Isolated replicas of real tools and identity systems, kernel and network specialists, formal-policy expertise, independent penetration testing, and incident-response capacity.

Crowdedness: High for empirical agent security and prompt injection; lower for formal, below-model enforcement tested against adaptive end-to-end attacks.

Tractability: High for benchmark and least-privilege improvements, medium for robust production patterns, and very low for broad formal containment guarantees.

Suggested starting points

  • Individual: Add a deny-by-default, provenance-aware least-privilege wrapper to AgentDojo and compare it with prompt-only defenses on both benign utility and adaptive indirect prompt injection.
  • Small lab: Combine AgentDojo, Agent Security Bench, and sandbox-escape tasks in gVisor or Firecracker; red-team delegation, memory, restart, exfiltration, and privilege transitions across four model families.
  • Well-funded lab: Build an isolated replica of a real enterprise tool environment with formal identity, network, filesystem, and approval policies; commission independent model red teaming and a conventional penetration test.
